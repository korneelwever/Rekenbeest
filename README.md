# Rekenbeest

Offline-first Dutch maths practice for primary-school children, with player-specific levels for addition, subtraction and multiplication. Built as a lightweight web app and Android WebView APK.

## Build the Android APK

The APK is a signed release build. It uses one persistent signing key so Android accepts future builds as updates.

### One-time signing setup

Create a private keystore on a trusted computer. Keep a secure backup. **Never commit the keystore or its passwords to this repository.** If the key is lost, Android will not accept future builds as updates to installations signed with it.

Run:

```bash
keytool -genkeypair -v -keystore tafelbeest-release.jks -alias tafelbeest -keyalg RSA -keysize 2048 -validity 10000
```

Encode the keystore as one Base64 string:

- macOS/Linux: `base64 -w 0 tafelbeest-release.jks` (on macOS, use `base64 tafelbeest-release.jks | tr -d '\\n'`)
- Windows PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("tafelbeest-release.jks"))`

In the GitHub repository, open **Settings → Secrets and variables → Actions** and add these repository secrets:

- `TAFELBEEST_KEYSTORE_BASE64`: the Base64 output
- `TAFELBEEST_KEYSTORE_PASSWORD`: the keystore password
- `TAFELBEEST_KEY_ALIAS`: `tafelbeest`
- `TAFELBEEST_KEY_PASSWORD`: the key password

Then open **Actions → Build Rekenbeest APK → Run workflow**. Download the `rekenbeest-release-apk` artifact from the completed run and install `app-release.apk`.

Every build gets a higher Android version code, and all builds use the same signing key.

### Important for the currently installed debug build

The old debug APK was signed with a temporary key generated by GitHub Actions. That private key is not available, so Android cannot update that installation with the new persistent key. You will need to uninstall the old app once, then install the first signed release APK. **Uninstalling clears the app's locally stored player profiles and progress**, so record anything you want to keep first.

The app stores progress locally on the device. No account or internet connection is required to play.

## Learning approach

Each player has a school group and separate difficulty levels for addition, subtraction and multiplication. School group selects sensible starting levels, which can then be changed independently from the home screen. Arithmetic levels cover number ranges and whether a question crosses a ten or requires borrowing. Multiplication levels unlock table groups progressively. Existing player profiles and multiplication mastery are retained when the app is updated.

Each multiplication fact is tracked separately. Incorrect answers reduce mastery and increase future practice frequency. Correct but slow answers also count as not-yet-automatic, while fast correct answers build mastery. The app tracks average response time and uses weighted selection to bring weaker facts back more often.


## Install as a web app

The repository root is a static PWA and can be deployed directly to any HTTPS static host, including Vercel. No build command or framework preset is required.

- English browser/device language selects the **Math Monster** install name.
- Other languages default to **Rekenbeest**.
- On iPhone or iPad, open the HTTPS site in Safari, choose **Share → Add to Home Screen**, then enable **Open as Web App**.
- The service worker caches the app shell and assets so the game can start offline after the first successful visit.

The current game interface and questions are still Dutch. The localized install name does not translate the game itself.
